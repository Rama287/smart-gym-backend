# Smart Gym Assistant Backend

This repository contains the backend part of the Smart Gym Assistant full-stack web application.

The backend was developed using Node.js and Express.js. It connects to a PostgreSQL database and provides API endpoints for authentication, user management, and workout management.

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- pg
- cors
- dotenv
- nodemon
